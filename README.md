# Employee Raise Issue – ServiceNow Application

## 📌 Project Overview

The Employee Raise Issue project is a custom ServiceNow application designed to manage and process employee raise-related requests.

This application provides a structured solution for creating, managing, and processing Employee Raise Issues.

---

## 🚀 Phase 1: Creating a Custom Application

A custom ServiceNow application was created with the following configuration:

- **Application Name:** Employee Center
- **Application Scope:** Scoped
- **Platform:** ServiceNow

### Steps Performed

1. Navigated to **All Menus**
2. Opened **App Engine**
3. Opened **ServiceNow Studio**
4. Clicked **Create**
5. Selected **App**
6. Created the application with the name:

   **Employee Center**

7. Selected:

   **Scoped Application**
